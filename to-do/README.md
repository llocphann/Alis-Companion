# Companion task tracking

All Companion feature, rework and bug tasks are managed in **[Alis-Companion GitHub Issues](https://github.com/llocphann/Alis-Companion/issues?q=is%3Aissue+is%3Aopen)**. This repository owns both implementation and its active task backlog. Original Alis Issues retain archival cross-links; do not update those archived copies.

Search and update the matching `[DOMAIN-F##]`, `[DOMAIN-R##]` or `[DOMAIN-I##]` Issue **in Alis-Companion** directly. Cross-repo dependencies link to the Alis/Intergration Issue rather than duplicating its ownership. New task → one concise Issue; changed scope → edit its body; meaningful milestone → brief comment with tested Alis/Companion SHAs and real result. Bot-complete tasks stay open awaiting Owner verification; close after explicit approval.

Never write new tasks or progress to `to-do/` Markdown.
