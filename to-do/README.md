# Companion task tracking

All Companion feature, rework and bug tasks are managed in **[Alis GitHub Issues](https://github.com/llocphann/Alis/issues?q=is%3Aissue+is%3Aopen)**. This repository owns source, tests, assets and receipts, **not a second task backlog**.

Search and update the matching `[DOMAIN-F##]`, `[DOMAIN-R##]` or `[DOMAIN-I##]` Issue directly. New task → one concise Issue; changed scope → edit its body; meaningful milestone → brief comment with tested Alis/Companion SHAs and real result. Bot-complete tasks stay open awaiting Owner verification; close after explicit approval.

Never write new tasks or progress to `to-do/` Markdown. [Historical visual](https://github.com/llocphann/Alis-Companion/blob/732136ef65bb3c84d9339207210c955759a85b76/to-do/cloud-bot/ABYSS_WATER_DROPLET_COMPANION.md) and [AI](https://github.com/llocphann/Alis-Companion/blob/732136ef65bb3c84d9339207210c955759a85b76/to-do/cloud-bot/WULL_LOCAL_AI.md) evidence remains source-pinned; don't modify Alis stable or enable optional sensors, models or privileged services without approval.
